# Статус задач

## Сделано и проверено на запущенном стеке

- [x] Docker Compose: PostgreSQL (3 БД), NATS JetStream, nginx, 5 сервисов; все контейнеры healthy
- [x] Проверка JWT RS256 в каждом сервисе, сервисные токены HS256, демо-токены `make tokens`
- [x] Загрузка CSV: 78 строк / 12 ПК → импорт `COMPLETED`
- [x] Ошибки строк и частичные снимки (`PARTIAL`), критические ошибки формата → `FAILED`
- [x] Повторный импорт того же файла идемпотентен; снимок со старшим `collected_at` → `SUPERSEDED`
- [x] Остановка NATS во время импорта → повтор публикации → `COMPLETED` после восстановления
- [x] Smart Matching: точное совпадение, pg_trgm кандидаты, задачи ручной проверки
- [x] Ручное подтверждение сопоставления обновляет баланс лицензий и находки
- [x] Compliance: дефицит Office и Photoshop, истёкший TeamViewer, запрещённое ПО, неподдерживаемые и устаревшие
      версии, неизвестное ПО, `LICENSE_UNVERIFIED`, `COMMERCIAL_USE_RESTRICTED`
- [x] Дашборд и аналитика; для сотрудника — урезанные данные только по себе
- [x] RBAC: сотрудник получает 403 на `/licenses`, не видит цен и соглашений
- [x] Чат: SSE (`message_start` / `delta` / `message_end`), у сотрудника нет инструментов с лицензиями
- [x] Анализ EULA (mock), кэш по хэшу текста, подтверждение администратором
- [x] `make smoke` проходит
- [x] Потребление памяти Go-сервисами 3–9 MiB в простое
