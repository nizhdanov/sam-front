# User Stories — фронтенд SAM «Сургутнефтегаз»

**Роли (2):**

- **Администратор SAM** — оператор: ведёт каталог, договоры, импорты, мэтчинг;
- **Обычный пользователь** —доступ к справочнику БПО, чат с ботом, которой возвращает только бесплатные лицензии .

## E0. Доступ и навигация

**US-01 [MVP]** — Как Администратор SAM, я хочу входить в систему и видеть меню в соответствии с одной из двух ролей, чтобы функции ведения данных были отделены от аналитики.

- Администратор SAM — полный CRUD во всех разделах; ИТ-директор — просмотр, аналитика и экспорт.
- Меню фильтруется по роли; прямой переход по URL к запрещённой функции — экран «Доступ запрещён».
- Разделы: Каталог ПО / Устройства и установки / Комплаенс / ИИ-разделы (Smart Matching, Чат-ассистент, анализатор лицензий) / Журнал.

## E1. Каталог ПО (единый справочник, не только БПО) Δ**US-02 [MVP] Δ** — Как Администратор SAM, я хочу вести единый каталог всех известных продуктов (не только перечень БПО) с признаком вхождения в перечень, чтобы комплаенс покрывал и коммерческое ПО вне БПО.

- Колонки: наименование, версия, издатель, раздел/класс классификатора, тип лицензирования, признак БПО / Вне БПО, статус (Актуальное / Устаревшее / Запрещённое), всего куплено мест.
- Фильтры: по разделу, классу, типу лицензии, статусу, признаку БПО; поиск по подстроке.
- Цветовая метка статуса в строке списка.

**US-03 [MVP]** — Как Администратор SAM, я хочу создавать и редактировать карточку продукта, чтобы эталонный каталог был полным.

- Форма: наименование, версии, издатель, назначение, раздел/класс, признак «в перечне БПО», лицензионное соглашение из справочника, статус.
- Удаление блокируется при наличии установок или договоров; статус «Запрещённое» требует комментария.

**US-04 [MVP]** — Как Администратор SAM, я хочу вести справочник лицензионных соглашений (GNU GPL v.2, MIT, Apache 2.0, EULA Microsoft и др.), чтобы однозначно классифицировать ПО.

- Атрибуты: наименование, тип (Open Source / Commercial / Trial; бесплатно / платно / условно-бесплатно), текст или файл.
- Лицензию нельзя удалить, пока на неё ссылаются продукты; счётчик использующих её продуктов в списке.

## E3. Устройства и фактические установки Δ (без данных о пользователях)

**US-07 [MVP] Δ** — Как Администратор SAM, я хочу вести реестр устройств по серийным номерам из выгрузки агента (включая VM-идентификаторы вида VMware-42 37 a3 72…), чтобы вся детализация велась от устройства, а не от сотрудника.

- Карточка устройства: серийный номер, тип, список установленного ПО, история импортов.
- Опциональные ручные поля «ответственный», «подразделение/кабинет» (текстовые, заполняются по мере появления данных; в расчётах не участвуют).
- Устройства из импорта, отсутствующие в реестре, создаются автоматически со статусом «Новое из выгрузки».

**US-08 [MVP]** — Как Администратор SAM, я хочу загружать CSV-выгрузку агента (серийник устройства, имя ПО, издатель, версия), чтобы фиксировать фактические инсталляции без ручного ввода.

- Предпросмотр первых строк до подтверждения; отчёт после импорта: загружено N, дублей M, ошибок K.
- Дедупликация по связке «устройство + имя ПО + версия»; повторная загрузка не создаёт дублей.
- KB-обновления (Security Update … (KB…)) помечаются «не ПО» и не попадают в учёт; нераспознанные имена уходят в очередь Smart Matching (US-14).

**US-09 [MVP]** — Как Администратор SAM, я хочу просматривать реестр установок в разрезах «по устройству» и «по продукту», чтобы отвечать на вопрос «что и где реально установлено».

- Запись: устройство, сырое имя из ОС, сопоставлённый продукт каталога, версия, дата фиксации.
- Фильтр по статусу распознавания: «соотнесено с каталогом» / «не распознано».

## E4. Комплаенс-контроль (ядро)

**US-10 [MVP]** — Как Администратор SAM, я хочу видеть дашборд KPI, чтобы за минуту оценивать лицензионную чистоту парка.

- Виджеты: всего устройств, инсталляций, % распознанного ПО, перелицензирование, простаивающие лицензии (куплено > установлено), запрещённое ПО, устаревшие версии, истекающие подписки.
- Клик по виджету ведёт на детальный список нарушений этой категории.

**US-11 [MVP] Δ** — Как Администратор SAM, я хочу видеть экран «куплено vs установлено» для любого продукта с платными лицензиями — по сумме мест действующих договоров, — чтобы находить штрафные риски и по БПО, и по коммерческому ПО вне БПО.

- Таблица: продукт, куплено (сумма договоров), установлено по факту, дефицит (красная подсветка: «MS Office: установлено 120 при 100 купленных — штрафной риск»), свободный остаток (жёлтая: «куплено 50, установлено 20 — простаивает 30»).
- Переключатель вида: «Коммерческое ПО» (по договорам) / «БПО — бесплатное» (лимита нет: контроль статуса и устаревших версий).
- Строка раскрывается в список конкретных устройств с этой установкой.

**US-12 [MVP]** — Как Администратор SAM, я хочу отдельный экран запрещённого и устаревшего ПО, чтобы контролировать юридические риски (после исключения роли ИБ экран закреплён за ИТ-директором).

- Факты установки запрещённого ПО: устройство, сырое имя, продукт, дата обнаружения.
- Вкладка «Устаревшие версии»: устройства с версией ниже актуальной из каталога.
- Отметка «обработано» с комментарием; экспорт списка.

## E5. ИИ: Smart Matching «грязных» имён (Кейс А)

**US-14 [ИИ]** — Как Администратор SAM, я хочу видеть очередь нераспознанных имён с предложениями ИИ-мэтча к каталогу (studio_visual_2022.exe → Microsoft Visual Studio 2022), чтобы быстро чистить данные.

- Очередь: сырое имя, издатель/версия, предложенный продукт, confidence.
- Действия: «Принять» / «Отклонить» / «Выбрать другой продукт»; подтверждённые мэтчи пересчитывают комплаенс без повторного импорта.

**US-15 [ИИ]** — Как Администратор SAM, я хочу, чтобы подтверждённые правила автоматически применялись к новым выгрузкам (порог confidence настраивается), чтобы не размечать одно и то же дважды.

- Раздел «Правила соответствия»: пары «сырое имя → продукт», редактирование и удаление.

## E6. ИИ: AI-анализатор лицензий / EULA

**US-16 [ИИ]** — Как Администратор SAM, я хочу загрузить текст лицензии и получить разбор от ИИ, чтобы не читать десятки страниц вручную.

- Загрузка файла (.txt/.pdf/.docx) или вставка текста; результат: тип лицензии, «коммерческое использование: да/нет/не определено», скрытые подписки и авто-продления, ограничения, риски — каждый пункт со ссылкой на абзац-источник.
- Кнопка «Сохранить в лицензию» записывает результат и предложенный тип.

**US-17 [ИИ]** — Как Администратор SAM, я хочу получать предложение привязки разобранной лицензии к стандартной из перечня (топ-3 по сходству), чтобы поддерживать единый справочник.

## E7. ИИ: Чат-ассистент

**US-18 [ИИ] Δ** — Как Администратор SAM, я хочу задавать вопросы на естественном языке («У кого стоит нелицензионный Photoshop?», «Сколько лицензий простаивает?») и получать аналитику, не строя запросы вручную.

- Ответ: краткий вывод текстом + таблица; кликабельные объекты ведут в карточки продуктов, договоров и устройств.
- Блок «Типовые вопросы»; ответы учитывают роль пользователя (административные данные ИТ-директору недоступны).
- В примерах ответов фигурируют устройства и договоры, а не сотрудники.

**US-19 [ИИ]** — Как Администратор SAM, я хочу видеть историю диалогов и выгружать таблицы из ответов в XLSX, чтобы возвращаться к аналитике.

---

## E8. Аудит

**US-20 [MVP]** — Как Администратор SAM, я хочу видеть журнал изменений справочников и данных (кто, когда, что), чтобы контролировать качество ведения системы.

- Колонки: дата, пользователь, объект, тип действия, краткое diff-описание; фильтры по пользователю, объекту, периоду.

**US-21 [ИИ] Δ** — Как Пользователь, я хочу задавать вопросы на естественном языке («У кого стоит нелицензионный Photoshop?», «Сколько лицензий простаивает?») и получать аналитику, не строя запросы вручную, но только по бесплатным лицензиям.

- Ответ: краткий вывод текстом какую версию использовать и запрещены ли те или иные лицензии
- Блок «Типовые вопросы»; ответы учитывают роль пользователя (административные данные обычному пользователю).

**US-22 [MVP]** — Как Пользователь, я хочу отдельный экран запрещённого и устаревшего ПО, чтобы контролировать и просматривать актуальные версии ПО установленного на моем компьютере.

- Факты установки запрещённого ПО: устройство, сырое имя, продукт, дата обнаружения.
- Вкладка «Устаревшие версии»: устройства с версией ниже актуальной из каталога.
